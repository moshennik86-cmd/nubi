НУБИ (누비) — КАК ПОСТАВИТЬ ПРИЛОЖЕНИЕ НА ТЕЛЕФОН
==================================================

Это настоящее приложение: проверка по GPS, карта, установка на главный экран
Android, работает без интернета (кроме карты). Бесплатно, без Google Play.

Нужно один раз выложить папку в интернет. Используем GitHub Pages — бесплатно и надолго.
Удобнее всего делать с компьютера (около 15 минут).


ШАГ 1. Аккаунт GitHub
----------------------
1. Откройте https://github.com и нажмите «Sign up».
2. Зарегистрируйтесь (почта, пароль, имя пользователя).
   Имя пользователя будет в адресе приложения, например: dima-nubi.github.io


ШАГ 2. Создать хранилище (репозиторий)
--------------------------------------
1. Справа вверху «+» → «New repository».
2. Repository name: nubi
3. Выберите «Public».
4. Нажмите «Create repository».


ШАГ 3. Загрузить файлы
----------------------
1. Распакуйте этот zip на компьютере.
2. На странице репозитория нажмите ссылку «uploading an existing file».
3. Откройте распакованную папку nubi-app, выделите ВСЁ ВНУТРИ неё
   (index.html, manifest.webmanifest, sw.js, папки css, js, icons)
   и перетащите в окно браузера.
   Важно: перетаскивать содержимое папки, а не саму папку nubi-app.
4. Внизу нажмите зелёную кнопку «Commit changes».


ШАГ 4. Включить сайт
--------------------
1. В репозитории: «Settings» → слева «Pages».
2. В разделе «Branch» выберите «main» и папку «/ (root)», нажмите «Save».
3. Подождите 1–2 минуты и обновите страницу. Наверху появится адрес вида:
   https://ВАШЕ-ИМЯ.github.io/nubi/


ШАГ 5. Установить на телефон
----------------------------
1. Откройте этот адрес на телефоне в Chrome.
2. Меню (три точки справа вверху) → «Установить приложение»
   (или «Добавить на главный экран»).
3. На экране появится значок 누비. Открывайте его как обычное приложение.
4. При первой отметке телефон спросит доступ к местоположению — нажмите «Разрешить».


КАК ПРОВЕРИТЬ ДОМА
------------------
Профиль → Настройки → «Тестовый режим». Тогда печать ставится без GPS.
Такие печати помечены как тестовые. Для настоящей проверки выключите режим
и сходите к любому месту (ближе всего — Ёнджуса и Юннын в Хвасоне).


КАК ОБНОВЛЯТЬ
-------------
Когда я пришлю новый zip:
1. Репозиторий nubi → «Add file» → «Upload files».
2. Перетащите файлы из нового zip (так же, содержимое папки).
   Одноимённые файлы заменятся сами.
3. «Commit changes». Через 1–2 минуты приложение на телефоне обновится
   (иногда нужно закрыть и открыть его заново).


ЧТО ВНУТРИ
----------
index.html            — главная страница
manifest.webmanifest  — название и значок для установки на телефон
sw.js                 — работа без интернета
css/style.css         — оформление
js/app.js             — логика приложения
js/geo.js             — GPS и расстояния
js/legends-main.js    — подробные легенды (Ёнджуса, Юннын, Гоннын, Хвасон, Эмилле, Аран, Чхамсондан)
js/legends-hwaseong.js — легенды Хвасона (Собонсан, побережье, Пондам и др.)
js/data.js            — регионы, челленджи, звания
js/i18n/ko.js, ru.js, en.js — тексты интерфейса на каждом языке
js/i18n/index.js      — список языков
icons/                — значки приложения


ВАЖНО
-----
• Пока всё (печати, ник, ваши легенды) хранится только на этом телефоне.
  Общий сервер, чтобы видеть других игроков и их легенды, — следующий этап.
• Координаты Ёнджуса, крепости Хвасон и колокола Эмилле приблизительные.
  Если на месте приложение говорит «далеко», напишите мне, сколько метров
  оно показывает, — поправлю.


ОБНОВЛЕНИЕ 2 — РЕЖИМ РАЗМЕТКИ
-----------------------------
У большинства мест Хвасона ещё нет точных координат («точка уточняется»).
Их можно записать самому:
1. Профиль → Настройки → включить «Режим разметки».
2. Прийти к месту легенды, открыть её и нажать
   «📍 Записать эту точку как место легенды».
3. С этого момента на этом телефоне по ней можно отмечаться.
4. В профиле появится список «Записанные точки» — нажмите
   «Скопировать и отправить разработчику» и пришлите мне в чат.
   Я внесу их в приложение для всех.
